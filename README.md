# 📱 Codomax – Mobile Development Internship

A hands-on journey into mobile application development, covering UI design, application logic, local databases, cloud integration, and advanced mobile technologies through practical projects.

## 🚀 Internship Projects

### 01. Mobile Development Fundamentals
An introduction to Android and iOS ecosystems, mobile application architectures, navigation, responsive layouts, and development environments. Focuses on understanding the foundations of mobile app development and designing basic application screens.

### 02. UI Development & Navigation
Development of interactive mobile interfaces using buttons, forms, lists, cards, and image assets. Focuses on multi-screen navigation, user input validation, and building a functional **Mobile To-Do Application** with task management and categories.

### 03. App Logic & Local Data
Exploration of application state management, JSON processing, device storage, and local databases. Involves building a **Mobile Expense Tracker** with expense categorisation, filtering, persistent storage, and total calculations.

### 04. APIs, Firebase & Authentication
Integration of REST APIs and Firebase services into mobile applications. Covers HTTP requests, JSON parsing, user registration, authentication, and cloud database management through a **Mobile Cloud Application**.

### 05. Advanced Mobile Development
Implementation of advanced mobile features, including notifications, device permissions, location services, camera and gallery integration, and performance optimisation. Focuses on developing a **Feature-Rich Mobile Application**.

### 06. Mobile App Capstone Project
A comprehensive application development project combining UI design, navigation, application logic, local databases, cloud authentication, and device hardware integrations. Includes technical documentation, architecture design, a demonstration video, and an APK build.
